# hop-tuan.md — Báo cáo tuần (không cần họp; mỗi người tự ghi, nguồn cho Phụ lục B)

Mẫu mỗi tuần (Chủ nhật, mỗi người tự thêm dòng của mình; biên tập chỉ gom):

```
## Sx — dd/mm
- PASS tuần này: <người: gói ID + file log evidence/...>
- Kẹt: <người: vấn đề, cần ai>
- Tuần sau nộp: <người: gói ID>
- Quyết định: <nội dung, ai đồng ý>
- Cổng / thi lại: <nếu có>
```
